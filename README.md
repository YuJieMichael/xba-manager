# 篮途经理 · 单机篮球经营游戏

从街头到超级联赛：同时经营一支街球队和一支职业队，培养球员、排兵布阵、打进篮途超级联赛。

## 在线玩
手机或电脑浏览器打开：**https://yujiemichael.github.io/xba-manager/**

手机上可以用浏览器的「添加到主屏幕」，像 App 一样全屏打开，断网也能玩。游戏更新后会在页面顶部提示「刷新更新」。

## 本地玩
运行 `node serve.js`，然后打开 http://localhost:8638 。也可以直接双击 `index.html`（这种方式没有离线缓存和更新提示）。

> 存档保存在浏览器里，跟浏览器、打开方式绑定。每个赛季结束游戏会提醒导出备份，备份文件可以在「存档设置」里导入。

## 玩法
- 街球队（3 人制，训练点养成）+ 职业队（5 人制，打联赛）双球队
- 联赛金字塔：4 个等级、15 个联赛、每联赛 14 队、26 轮，前 2 升后 4 降，季后赛、篮途杯、全明星
- 比赛引擎：14 种进攻方式、6 套进攻战术、6 套防守战术互相克制；进攻核心 / 主防对象、领先落后换战术、战术熟练度、体能轮换
- 文字直播 + 技术统计
- 训练、潜力、升星、特长徽章、球员性格（领袖、大心脏、微波炉……）
- 职员、球场、门票、球衣、广告、税收等经营系统
- 转会：自由球员、选秀、明拍 / 暗拍、球星挂牌、球员交易、球探、选拔卡
- 街球杯赛、胜者为王、联盟、经理技能、成就、名人堂、重生

其他球队都由 AI 经理运营。游戏币只能通过比赛、目标、奖项赚取，或用球队资金限量兑换。

## 开发

### 测试
需要 Node.js，不依赖任何 npm 包：

```
node tests/run.js         # 完整回归测试（约 2 分钟，含战术平衡矩阵）
node tests/run.js quick   # 跳过战术矩阵
node tests/tactics.js 200 # 打印 6×6 战术胜率矩阵（每格 200 场）
```

测试用 `XBA.U.seed(n)` 固定随机数，同一种子结果完全一致。每次提 PR 和推送到 main 时，GitHub Actions 会自动跑快速测试。

### 发布新版本
1. 把 `js/version.js` 里的 `XBA.VERSION` 和根目录 `version.json` 改成同一个新版本号（测试会检查两者一致）
2. 在 `CHANGELOG.md` 写上这次的改动
3. 合并到 main，GitHub Pages 自动部署；玩家打开游戏时会看到「新版本已发布」提示

### 改存档结构
把 `js/version.js` 里的 `XBA.SAVE_VER` +1，在 `js/migrate.js` 的 `STEPS` 末尾加一步升级函数。旧存档读档或导入时会逐级升级；旧页面读到新存档会提示刷新，不会把存档写坏。
