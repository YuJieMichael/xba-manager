# XBA篮球经理 · 单机复刻版

## 在线玩
手机或电脑浏览器打开：**https://yujiemichael.github.io/xba-manager/**

手机上可以用浏览器的「添加到主屏幕」，像 App 一样全屏打开。

## 本地玩
直接双击 `index.html` 用浏览器（Chrome / Edge）打开即可，进度自动保存在浏览器里。
也可以运行 `node serve.js`，然后打开 http://localhost:8638 。

> 存档跟浏览器、打开方式绑定（双击打开和 localhost 打开是两份存档）。建议在「存档设置」里定期导出备份。

## 已复刻的内容
- 街球队（3 人制，训练点养成）+ 职业队（5 人制，打联赛）双球队
- 联赛金字塔：4 个等级、15 个联赛、每联赛 14 队、26 轮，前 2 升后 4 降
- 比赛引擎：原版手册里的 14 种进攻方式、6 套进攻战术比率表、6 套防守克制表、位置能力侧重表；进攻核心 / 主防对象、领先/落后 15 分换战术、战术熟练度等级、阵容状态（工资帽）
- 文字直播（实时回放）+ 技术统计
- 训练：街球训练点加点（一次最多 +3）、职业队每日训练项目、潜力颜色条、潜力星级
- 职员：训练员 / 营养师 / 队医（低级职员里藏着 10% 的“宝藏”）
- 经营：门票（可调票价）、球衣、广告（球迷数/4000+1）、球场升级、奢侈税、赛季所得税
- 转会：街头自由球员（暗拍）、街球选秀、职业转会（明拍）、极限球员（赛季中开放）、街头竞价、球探、选拔卡（绿名本土球员）、职业选秀
- 街球杯赛（新人杯 / 小杯赛 / 大杯赛）、训练赛、友谊赛、表演赛、胜者为王
- 老化、退役、伤病、生日长岁、意识（谈话）、隐藏属性

其他球队由 AI 经理运营；联盟、真人约战等多人功能没有复刻。

## 测试
需要 Node.js，不依赖任何 npm 包：

```
node tests/run.js         # 完整回归测试（约 2 分钟，含战术平衡矩阵）
node tests/run.js quick   # 跳过战术矩阵
node tests/tactics.js 200 # 打印 6×6 战术胜率矩阵（每格 200 场）
```

测试用 `XBA.U.seed(n)` 固定随机数，同一种子结果完全一致。改了比赛引擎或数值后跑一遍，确认没有出现「万金油」战术、存档没有暴涨。
